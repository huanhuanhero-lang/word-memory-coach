# 用户反馈记录

## 使用说明
每条反馈尽量记录事实和原话，区分“观察到的问题”和“解决方案假设”。新增反馈按时间倒序添加。

## 反馈模板
- 日期：
- 版本：
- 使用场景：
- 孩子完成了什么：
- 卡住位置：
- 孩子原话：
- 家长观察：
- 是否主动再次使用：
- 错误类型：
- 我的判断：
- 建议改动：
- 优先级：高 / 中 / 低

## 已有产品反馈
### 反馈001：需要成就感与有创意的激励
- 来源：家长产品讨论
- 结论：激励不能只做连续打卡，应奖励掌握、修复错词、完成找特位等能力成长。
- 后续：设计能力型成就和家长可配置奖励。

### 反馈002：家长需要自主配置
- 来源：家长产品讨论
- 结论：注册后允许自主设置每日时长、学习数量、提醒方式、奖励方式和竞争开关。
- 后续：设计家长配置向导。

### 反馈003：产品必须主动教记忆方法
- 来源：家长产品讨论
- 结论：产品定位从“背单词工具”调整为“单词记忆教练”，必须加入发音、音标、分段、归位、找特位和主动回忆。
- 后续：优先开发记忆教练卡。

### 反馈004：视频练习案例
- 来源：教学视频画面
- 观察：张嘉豪的 dictionary、biology、ambulance、technology通过，geography未通过。
- 判断：错词应回到分段、归位、合成流程，而不是只记录错误。
- 后续：geography作为首批专项练习案例。
