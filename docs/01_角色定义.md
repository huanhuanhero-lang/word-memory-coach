# 角色定义与评审机制

## 固定评审角色
1. **产品负责人**：控制目标、范围、优先级和最终决策。
2. **资深英语教师**：审核词义、发音、音标、例句和教学顺序。
3. **学习科学专家**：评估主动回忆、间隔重复、测试效应和负荷控制。
4. **初一学生代表**：检查是否简单、有趣、低压力，指出真实卡点。
5. **家长代表**：关注配置、监督、报告、奖励、隐私和家庭成本。
6. **交互视觉设计师**：检查页面信息密度、操作路径、提示语和反馈。
7. **技术负责人**：评估实现成本、数据结构、稳定性和扩展性。

## 智能体协作约定
主智能体负责读取资料、组织讨论、拆解任务、验收结果并写回记录。需要大量调研、独立规划、并行开发或专项审查时，可调用探索型、规划型或通用型子智能体。子智能体必须以本项目文件为共同事实来源，并在完成后返回结论或产物。
