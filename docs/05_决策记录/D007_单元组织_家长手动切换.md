# D007｜单元组织方式：家长手动对齐学校进度

- 日期：2026-09-10
- 议题：1 个单元扩到 10 个单元后，单元组织方式：混在一起 / 强制选 / 自动解锁 / 手动切换
- 背景与冲突点：
  - 当前 MVP 只有 Unit 1（~6 词，待扩到 30 词），未来需 10 单元 ~300 词。
  - D007 初稿曾提议"按顺序推进 + 学完自动解锁下一单元"，但用户**明确反对自动解锁**——
    > "我觉得是不是可以让家长或学生选择，当前学校正在学习的单元，如果学校学到下一个单元，用户就切换到下一个单元"
  - 真实场景：孩子的学习进度跟学校课本走，应用不该"替"孩子决定什么时候进下一单元。
  - 自动解锁的问题：
    1. 家长无法控制节奏（孩子没复习好就跳下一单元）
    2. 跨教材/版本不一致（有人学人教版、有人学外研版）
    3. 学校进度可能跳跃（期中/期末/假期），不是匀速
- 各角色观点摘要：
  - 产品负责人：**强烈同意用户观点**。"自动解锁"是产品经理的傲慢，单元进度必须由人和学校共同决定。
  - 资深英语教师：单元必须按课本走，复习可以跨单元；切换要"零成本"（1 步操作），否则家长懒得切。
  - 学习科学专家：单元是**编码阶段的脚手架**，但**检索阶段必须跨单元**；切换频率低（每 1-2 周一次），不会破坏算法。
  - 初一学生代表："让我自己能切，不想每次问家长"——意味着切换入口要让学生也找得到。
  - 家长代表："我要能一眼看到当前在学哪个单元，跟学校对一下"——主 CTA 旁边必须有单元标识。
  - UI 设计师：首页主 CTA 永远"开始学习"，单元切换放底部"小圆点行"或"齿轮里的二级菜单"，不抢主 CTA。
  - 技术负责人：`data/unit1.json` ~ `unit10.json` 独立文件已经预留好，`loadWords(unitId)` 改一行即可；缺的是 `settings.current_unit` 字段和切换 UI。
- 最终决策：**家长/学生手动切换单元 + 跨单元复习**。
  - `settings.current_unit`：当前正在学的单元（默认 1）
  - **没有"自动解锁"概念**——所有已加载 unit 全部可切换
  - 切换路径：首页底部"📖 切换单元"行（小字 + 单元圆点）
  - 今日队列：`当前单元未学新词` + `全单元待复习词`（复习打散跨单元）
  - 家长配置页可设置默认起始单元（新档案时用），也可在首页实时切换
- 决策人/讨论来源：用户洞察 + 7 角色评审（产品 + 教师 + 家长 三方主导）
- 备选方案与放弃原因：
  - 放弃「全混合，不显示单元」：家长无法对齐学校进度；学生失去"完成单元"的成就感。
  - 放弃「强制每次选单元」：学生每次进应用多一步操作，违反"点开始就学"的 MVP 原则。
  - 放弃「按顺序推进 + 学完自动解锁」：替家长/学生做决定；与学校进度脱节。
  - 放弃「家长锁定单元，学生不能切」：高年级学生想跳单元复习时会卡住。
- 决策后的影响：
  - **新增**：
    - `settings.current_unit = 1`（默认 Unit 1，可改）
    - `data/unit2.json` ~ `unit10.json`（10 个独立文件，沿用 unit1 结构）
    - `App.loadWords(unitId)` 支持按编号加载，缓存按 unitId 维度
    - `App.getTodayWordQueue()` 改为：
      1. 取 `settings.current_unit` 的未学新词（优先补满 daily_words）
      2. 不足时，跨所有已加载 unit 取待复习词
    - 首页新增"📖 切换单元"行（底部"卡片 3"位置）
    - 切换单元后立即刷新首页 + toast 提示
  - **修改**：
    - 首页主 CTA 副标题增加："Unit 3 · 第 4/30 词"（让家长一眼看到当前单元）
    - 学习记录 / 错词本 保留跨单元统计
    - 家长配置页增加"📖 默认单元"字段（新档案 / 切换时使用）
  - **保留**：
    - 错词本跨单元、复习打散跨单元、教师逐词审核字段 `reviewed_by`
- 需要验证的假设：
  - H1：家长/学生真的能记住"学校学到哪了"——可能需要 2 周提醒一次的"是否切单元"提示。v0.4 试用时观察。
  - H2：跨单元复习时，词数差很大（Unit 1 学 30 词，Unit 5 才学 5 词），复习队列会"偏"——待学习科学专家给出权重算法。
  - H3：切换到尚未学完的上一单元是否要做"半路切回"提示——v0.5 评估。
- 验收标准（v0.4）：
  1. 首页主 CTA 永远"开始学习"，不要求先选单元。
  2. 主 CTA 副标题显示当前单元（"Unit 3 · 第 4/30 词"）。
  3. 底部"📖 切换单元"入口可见，1 次点击可切到任意已加载 unit。
  4. 切换单元后，今日队列立即刷新，toast 提示"已切到 Unit X"。
  5. 复习词跨所有 unit 抽取（错词本 + 间隔复习）。
  6. `data/unit2.json` ~ `data/unit10.json` 文件就位（或至少有占位 unit2.json 验证加载机制）。
  7. `settings.current_unit` 字段持久化，刷新页面后保留。
- 版本：v0.4（D007 覆盖 D007 初稿"自动解锁"部分）
