# D001｜MVP 第一版增加"听写"环节

- 日期：2026-09-10
- 议题：是否在 MVP 第一版的记忆教练卡流程中增加"听写"环节（模仿老师朗读，学生在作业本上书写）
- 背景与冲突点：
  - 当前 P0 流程已有"主动回忆"（屏幕打字默写），但缺少纸笔书写环节。
  - 学校老师最常用的巩固手段是课堂听写，孩子对此有强仪式感。
  - MVP 范围是否进一步扩大，存在争议：产品负责人/学习科学专家支持，UI 设计师担心信息过载，技术负责人担心 TTS 限制。
- 各角色观点摘要：
  - 产品负责人：听写是真实掌握的检验手段，建议纳入 MVP。
  - 资深英语教师：听写分单词和短语/例句两层，节奏"两遍"——连读 + 慢速分段。
  - 学习科学专家：纸笔有"生成效应"增益，但必须有批改 + 归因闭环。
  - 初一学生代表：喜欢"像考试"的感觉；怕写错挨骂，需要"错了不扣分只入错词"。
  - 家长代表：强烈支持，但要求不增加家长负担，MVP 不要做拍照识别。
  - 交互视觉设计师：听写页只留播放/暂停/重听/下一题四个按钮，屏幕不显示单词。
  - 技术负责人：v0.1 不做中文释义朗读，不做拍照 OCR；用家长/孩子自评过渡。
- 最终决策：**在 MVP 第一版加入"听写"环节**，作为 P0 必做项。
- 决策人/讨论来源：用户提议 + 7 角色评审（产品负责人最终拍板）
- 备选方案与放弃原因：
  - 放弃"v0.1 不做听写"：错失纸笔生成效应，错过"像考试"的仪式感驱动。
  - 放弃"v0.1 立即做拍照 OCR"：技术成本和测试成本都过高。
  - 放弃"在跟读页内嵌听写"：会与"跟读"语义混淆。
- 决策后的影响：
  - 主流程更新为：**听音 → 跟读 → 分段 → 归位 → 找特位 → 合成 → 主动回忆 → 听写 → 间隔复习**
  - 词库 JSON 新增字段：`dictation_supported` (bool)、`dictation_pause_ms` (int, 默认 800)。
  - 新增 P0 任务"开发听写环节：TTS 播放 + 自评反馈 + 错词归档"。
  - 学习记录新增"听写错"标签，错词本支持按标签筛选。
- 需要验证的假设：纸笔听写 vs 屏幕打字，对初一学生的长时记忆增益是否显著。
- 验收标准：
  1. 听写页只显示"播放/重听/下一题"三个按钮，屏幕不显示单词。
  2. 每组 5 个词，支持"正常连读"和"慢速分段"两档。
  3. 自评/家长勾对后，写错的词自动进入错词本并打"听写错"标签。
  4. TTS 跨平台测试覆盖：Chrome / Edge / Safari iOS / 微信内置浏览器。
