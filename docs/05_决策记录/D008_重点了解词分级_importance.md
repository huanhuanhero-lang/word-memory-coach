# D008｜重点/了解词分级：课本加粗=重点（必会）+ 听写/复习加权

- 日期：2026-09-10
- 议题：词库 ~300 词要不要区分「重点必会」和「仅了解」？怎么区分？听写和复习要不要按重要性差异化？
- 背景与冲突点：
  - 用户录入的 2022 版课标 10 单元词表约 300 词，全部同等对待会导致：
    1. 听写泛泛（人名/地名也强迫默写，无意义）
    2. 复习时该重点的词和该了解的词一起随机，效率低
    3. 学生对"哪些是必会的"无感知
  - 课本本身用**加粗**区分了重点词，但当时没录入。
- 各角色观点摘要：
  - 产品负责人：**强烈需要分级**。否则听写失去意义（人名/地名/词组不该默写）。
  - 资深英语教师：按课本加粗定 `key`（必会），常规体定 `normal`（了解）；重点词进听写 + 复习加权。
  - 学习科学专家：复习算法对 `key` 词应优先（更高出现频率 + 错一次扣 2 分）；`normal` 词低频穿插（认得出即可，不强求默写）。
  - 初一学生代表：希望"重点"有显式提示（"⭐ 必会词"角标），减轻被测时不知道哪些该会的焦虑。
  - 家长代表：学习记录里要分开统计重点/了解的进度，方便家长知道"重点词掌握度"。
  - UI 设计师：`importance` 角标用 `key` 红 / `normal` 灰，避免再加一档"难度"颜色。
  - 技术负责人：仅在数据层加 `importance: "key" | "normal"` 字段，算法层加 2 个过滤器即可，无破坏性改动。
- 最终决策：
  - `data/unitN.json` 每词加 `importance: "key" | "normal"`，**判定标准=课本加粗**（重点=必会）。
  - **听写环节只抽 `key` 词**（人名/地名/词组不强迫默写）。
  - **复习算法对 `key` 词加权**：错一次扣 `2 分`，`normal` 错一次扣 `1 分`。
  - **UI 提示**：记忆教练卡和错词本每词加 `⭐ 必会` / `·了解` 角标。
  - **统计拆分**：学习记录里分别显示"重点词掌握度"和"了解词熟悉度"。
- 决策人/讨论来源：用户 2026-09-10 提出 + 7 角色评审
- 备选方案与放弃原因：
  - 放弃「全部同等对待」：听写和复习失去针对性，违背产品"主动回忆+听写"的核心目标。
  - 放弃「按词性分（实词/虚词）」：与课本意图不符（动词如 have 可能是了解词，名词如 family 可能是重点词）。
  - 放弃「1-5 权重表 + 人工名单」：维护成本高，权威依据（考纲）目前无版本可参考。
- 决策后的影响：
  - **数据层**：
    - `app/data/unit1.json` ~ `unit10.json` 每词加 `importance: "key"` 或 `"normal"`（已录入）
    - `meta.schema_notes` 注明判定规则
  - **算法层**：
    - `App.getTodayWordQueue`：今日新词**优先取 key 词**填满 daily_words；不足再补 normal
    - `App.getCrossUnitReviewQueue`：key 词排序优先（按 `importance` desc + `last_seen` desc）
    - `App.getDictationQueue`（新增）：只取 `importance: "key"` 的当前 unit 词
  - **UI 层**：
    - 记忆教练卡顶部加 `importance-badge` 角标
    - 错词本列表每行加角标
    - 学习记录加"重点 / 了解"分类统计
  - **统计层**：
    - `Store.getStats()` 新增 `key_total / key_mastered / normal_total / normal_mastered`
- 需要验证的假设：
  - H1：课本加粗=重点的判定是否准确？拟在教师审核时反向校验。
  - H2：仅 key 词进听写，是否会让 normal 词永远学不会？答：normal 词仍出现在记忆教练卡 8 步流程中（听音/跟读/分段/合成/主动回忆），只是跳过听写。
  - H3：复习加权（key 错一次扣 2 分）会不会让 key 词被反复"拖"复习，淹没 normal 词？v0.4 试用观察。
- 验收标准（v0.4）：
  1. `data/unit1.json` ~ `unit10.json` 每词含 `importance` 字段
  2. 记忆教练卡每词显示 `⭐ 必会` 或 `·了解` 角标
  3. 听写入口（如首页"听写 5 个"按钮）只抽当前 unit 的 key 词
  4. 复习时 key 词优先于 normal 词出现
  5. 学习记录页能分别看"重点 / 了解"进度
  6. `Store.getStats()` 返回 `key_mastered / normal_mastered` 等分类数据
- 版本：v0.4
