# D005｜撤销 D004，改为"每个 TTS 场景遍数可配置"

- 日期：2026-09-10
- 议题：原 D004（听音环节男女声组合）UI 体验过重，改为"每个 TTS 场景遍数可配置"
- 背景与冲突点：
  - 用户反馈：v0.3.1 的"👨 → 👩"主按钮 + "只听 👨 / 只听 👩"两个副按钮 + 实时进度提示 = UI 过重。
  - 用户真实诉求："每个流程的遍数在设置里配好，默认 1 遍就好"——是**配置项**，不是**操作选项**。
  - D004 的"声纹差异化教学法"在评审里有支持，但 UI 实现路径错误：让用户每次点都思考，是反人性的。
- 各角色观点摘要：
  - 产品负责人：强烈赞同。遍数是配置项，不是操作项。
  - 资深英语教师：默认次数应按教学逻辑定（跟读/合成 × 2，其他 × 1）。
  - 学习科学专家：上限 3 次，避免拖垮注意力。
  - 初一学生代表：默认 2 遍（听音 / 跟读 / 合成），其他 1 遍。
  - 家长代表：总配置项 ≤ 5 个，避免家长疲劳。
  - UI 设计师：听音页回归 1 个按钮，加"× N"角标。
  - 技术负责人：去掉 playWordDual 男女声逻辑，回归 playRepeat 统一 API。
- 最终决策：**撤销 D004 男女声方案，改为每个 TTS 场景遍数可配置。**
- 决策人/讨论来源：用户反馈 + 7 角色评审（产品 + 教师 + UI 主导）
- 备选方案与放弃原因：
  - 放弃"保留 D004 男女声 + 加遍数"：UI 复杂度和 1 个版本 = 2 倍升级风险。
  - 放弃"在每张卡显示遍数 stepper"：记忆卡是孩子用的，加 stepper 反而干扰。
  - 放弃"全局统一遍数"：不同教学环节节奏不同，统一会破坏教学法。
- 决策后的影响：
  - **撤销**：TTS.playWordDual、TTS.detectedDualVoice、TTS.preferred.male/female、TTS.fallbackMode。
  - **新增**：
    - TTS.playRepeat(text, { times=1, gapMs=600, onComplete }) 统一 API。
    - settings 新增 repeat 子对象：
      - `repeat.ear = 1`（听音）
      - `repeat.example = 1`（听例句）
      - `repeat.follow = 2`（跟读）
      - `repeat.syllable = 1`（分段）
      - `repeat.combine = 2`（合成）
      - `repeat.dictation = 2`（听写朗读）
    - settings.dictation_two_phase = true（连读+分段 toggle）。
  - **修改**：
    - 听音页回归 1 个"🔊 听"按钮 + 1 个"听例句"按钮，每个按钮右上角加"× N"小角标。
    - 家长配置页"发音"卡片重写为 5 个 stepper + 1 个 toggle。
    - 听写页的"开始朗读"按 dictation × dictation_two_phase 组合播放。
- 需要验证的假设：
  - H1：教师方案默认值（听音 × 1 / 跟读 × 2 / 合成 × 2）是否真的符合初一节奏——拟在试用 5 天后回访。
  - H2：stepper 上限 3 次是否够用——可能个别长词需要 4 次，待 v0.4 评估。
- 验收标准：
  1. 听音页只有 1 个"🔊 听"按钮，回归简洁。
  2. 按钮右上角显示"× N"小角标。
  3. 家长配置页"发音"卡片用 stepper 控件，每行 1-3。
  4. 听写朗读 toggle 默认开，关闭后只剩连读。
  5. 整套 TTS 播放无 console 错误。
  6. D004 男女声相关代码完全清除（grep 无 `playWordDual` / `dualVoice` 残留）。
- 版本：v0.3.2（覆盖 v0.3.1 范围）
