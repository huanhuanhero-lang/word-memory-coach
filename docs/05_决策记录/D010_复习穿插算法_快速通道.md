# D010｜复习穿插算法：优先级队列 + 复习快速通道

- 日期：2026-09-11
- 议题：复习词穿插在生词中的算法、复习词的快速通道、复习角标
- 背景与冲突点：
  - 用户 2026-09-11 洞察：**复习不该是独立模块，而应"穿插"在生词中**。
  - 当前 `getTodayWordQueue`：5 词队列 = 当前 unit 生词 + 跨 unit 复习词（复习词压到队列尾，无穿插算法）
  - 学习科学证据：艾宾浩斯遗忘曲线 1/2/4/7/15 天复习间隔；70/30 生/复比例是经验最优
  - 真实需求：错词应优先复习、key 词应优先复习、新词应尽快接触
- 各角色观点摘要：
  - 产品负责人：**穿插而非独立模块**。每次学习都有巩固。
  - 资深英语教师：复习词应有"复习"角标让学生知道"这个我之前错过"。
  - 学习科学专家：70/30 比例；priority 公式应包含 `recency + dictation_errors + recall_errors + importance`。
  - 初一学生代表：复习要简短，跳过找特位/合成，只走"听音→主动回忆→听写"3 步。
  - 家长代表：错词本要统计"今天复习 N 次"。
  - UI 设计师：复习词走"快速通道"标识（橙色 + 🔁 图标）。
  - 技术负责人：算法 = 候选池 → priority 公式 → 穿插规则；改动可控。
- 最终决策：
  - **候选池**：当前 unit 未 seen 生词 + 跨 unit 已 seen 复习词
  - **Priority 公式**（D008 + D010 综合）：
    ```
    priority = 
      + dictation_errors * 2      // 听写错一次 +2
      + recall_errors * 1.5       // 主动回忆错 +1.5
      + (importance === 'key' ? 1 : 0)  // key 词 +1
      - (last_status === 'master' ? 1 : 0)  // 已掌握 -1
      + (days_since_seen > 0 ? min(days_since_seen / 7, 2) : 0)  // 久未学 +0~2
      + (last_seen == null ? 0.5 : 0)  // 新词基础分
    ```
  - **穿插规则**：5 词队列中**复习词 ≤ 2 词**（硬上限），不足 5 时补生词
  - **复习词快速通道**：仅 3 步（听音 → 主动回忆 → 听写），跳过跟读/分段/归位/找特位/合成
  - **复习词角标** `🔁 复习`（橙色，记忆教练卡顶部显示）
  - **学习记录**：`study_log` 加 `study_type: 'new' | 'review'`；学习记录页加"今日复习 N 词 M 次"统计
- 决策人/讨论来源：用户 2026-09-11 洞察 + 7 角色评审
- 备选方案与放弃原因：
  - 放弃「独立复习模块」：用户已明确反对——重复劳动、低效。
  - 放弃「30% 比例死算」：用硬上限（≤ 2/5）更可控，避免极端情况（5 词全复习）。
  - 放弃「复习词走 8 步完整流程」：复习词 = 巩固为主，跳过精细加工节省时间。
- 决策后的影响：
  - `app.js` `getPriorityQueue` 替换 `getTodayWordQueue`
  - `renderCard`：根据 `word._studyType === 'review'` 切换 8 步 ↔ 3 步
  - `storage.js` `recordStudyLog`：加 `study_type` 字段
  - `Store.getStats()` 返回 `review_today` / `new_today` 分类
- 验收标准（v0.4.x）：
  1. 5 词队列中复习词 ≤ 2 词
  2. 复习词走 3 步快速通道（听音→主动回忆→听写）
  3. 复习词角标 `🔁 复习` 可见
  4. `study_log` 含 `study_type` 字段
  5. 学习记录显示"今日复习 N 词 M 次"
- 版本：v0.4.x
