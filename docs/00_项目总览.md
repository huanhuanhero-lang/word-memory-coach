# 单词记忆教练｜项目总览

## 1. 项目定位
帮助初一学生真正记住英语单词和常用短语的“单词记忆教练”，不是单纯的打卡或进度记录工具。

## 2. 核心目标
- 让学生掌握可迁移的记忆方法：发音、音标、分段、音形对应、找特位、主动回忆。
- 用短时、高频、低压力的学习流程建立持续使用习惯。
- 通过可见的能力成长和阶段性成就感，提升学习动力。
- 让家长可以自主配置学习时长、数量、提醒和奖励方式。

## 3. 当前MVP
- 教材范围：人教版七年级上册 Unit 1。
- 技术方向：HTML + CSS + 原生 JavaScript + JSON + localStorage + 浏览器 TTS。
- 核心页面：首页、今日挑战、记忆教练卡、错词强化、学习记录。
- 核心流程：听音 → 跟读 → 分段 → 归位 → 找特位 → 合成 → 主动回忆 → 间隔复习。

## 4. 已确定原则
1. 内容准确优先，必须受教材版本约束。
2. 每个单词不仅展示词义，还要主动教记忆方法。
3. 激励围绕掌握和能力成长，不只奖励打卡天数。
4. 家长配置应自主、灵活，并避免增加家庭沟通成本。
5. 先用简单方案验证真实效果，再扩展账号同步和AI能力。
6. **数据分层存储**（D003）：内容数据走 Git + 静态 JSON；用户数据 v0.1 走 localStorage；云服务 v0.3 之前不引入。
