### v0.3.2｜TTS 遍数可配置（撤销 D004，启用 D005）
- 日期：2026-09-10
- 背景：v0.3.1 的"👨 → 👩"主按钮 + "只听 👨/👩"副按钮 + 实时进度提示被用户反馈"UI 过重"。撤销 D004 男女声方案。
- 本次新增：
  - **D005 听音环节回归简洁**：1 个"🔊 听单词" + 1 个"听例句"按钮，按钮右上角显示"× N"角标（仅 N>1 时）。
  - **统一 TTS.playRepeat API**：onend 串联，不用 setTimeout 估算。
  - **家长配置页"🔊 发音"卡片重写**：6 个 stepper 控件（−/+ 1-3 范围）+ 1 个听写 toggle + TTS 语速。
  - **6 个可配遍数**：听音 / 听例句 / 跟读 / 分段 / 合成 / 听写朗读，每个 1-3 范围。
  - **听写朗读模式 toggle**：默认"连读 × 2 后慢速分段"；关闭后只连读。
  - **默认值按教师方案**：听音 1 / 听例句 1 / 跟读 2 / 分段 1 / 合成 2 / 听写 2。
- 本次修复：
  - 撤销 D004 的男女声所有代码（playWordDual / detectedDualVoice / dual_voice_mode 等）。
  - 听音 / 跟读 / 合成 / 分段按钮全部接统一 TTS.playRepeat。
- 已知问题：
  - 默认值是否符合初一节奏需 v0.2 真实试用回访。
  - stepper 上限 3 次是否够用待 v0.4 评估。
- 验证结论：
  - 听音页 UI 简洁化（自动化测试通过）。
  - stepper 控件 1-3 范围限制工作正常（点 + 上限 3）。
  - 角标"× N"在听音页正常显示。
  - 听写页 3 按钮 UI 不变，无 console 错误。
