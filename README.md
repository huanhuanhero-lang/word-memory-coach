# 单词记忆教练 · v0.4 MVP

> 帮助初一学生真正记住英语单词和常用短语。MVP 验证版。

## 🎯 一句话定位
不是打卡工具，而是**主动教你"怎么记单词"的教练**。

## 🧠 记忆卡 8 步流程
**听音 → 跟读 → 分段 → 归位 → 找特位 → 合成 → 主动回忆 → 听写**

每一步都有"为什么这样做"的教学逻辑，不是简单刷卡片。

## 🚀 立即使用

### 方式 1：本地起静态服务（推荐，TTS 在 file:// 下部分浏览器不工作）
```bash
cd d:\Project\traeWorkFolder\单词记忆教练\app
python -m http.server 8080
# 浏览器打开 http://localhost:8080
```

### 方式 2：直接双击 `app/index.html`
部分浏览器（Chrome/Edge）支持 `file://` 协议，但 iOS Safari 一定要起服务。
